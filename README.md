# AfriCalc — الحاسبة المبسطة لتجارة COD في إفريقيا

تطبيق ويب عربي بسيط يساعد على حساب **رأس مال استيراد المنتجات** و**سعر بيع القطعة** مع اختيار بلد الشحن: **دبي أو الصين**. جاهز للنشر على GitHub Pages، ولا يحتاج إلى تسجيل أو خادم.

## طريقة الاستعمال

1. اختر دولة البيع وبلد الشحن: دبي أو الصين.
2. أدخل ثمن القطعة بالدرهم المغربي، الكمية، وزن القطعة، تكلفة الإعلان **لكل طلب ناجح**، والربح المطلوب **لكل قطعة**.
3. ستظهر نتيجتان مباشرة: رأس مال الاستيراد وسعر بيع القطعة.

السنغال: رسوم الخدمة **84 درهماً**.

في حالة الشحن من الصين إلى **كوت ديفوار**، اختر «منتج عادي» أو «بطاريات أو سوائل» لأن التعريفتين مختلفتان. بالنسبة **للكاميرون والسنغال**، لم يتضمن جدول الصين تعريفة لهما، ولهذا يتطلب التطبيق إدخال التعريفة يدوياً **بالدرهم/كغ** بدل اختراع سعر.

## المعادلات

```text
الوزن الكلي (كغ) = وزن القطعة (كغ) × عدد القطع
شراء المخزون = ثمن القطعة × عدد القطع
شحن المخزون = الوزن الكلي × شحن الكيلوغرام بالدرهم
رأس مال الاستيراد = شراء المخزون + شحن المخزون
سعر بيع القطعة = ثمن القطعة + شحن القطعة + رسوم الخدمة + إعلان الطلب + الربح المطلوب
```

رسوم الخدمة تُحتسب مرة لكل طلب، بافتراض **قطعة واحدة لكل طلب**. لا يحسب البرنامج ميزانية الإعلان التي تحتاج دفعها مقدماً، ولا الإلغاءات ورسوم الإرجاع الإضافية أو الجمارك والضرائب إن وجدت.

## البيانات المعتمدة

- **أسعار الشحن من دبي** ورسوم الخدمة: الأرقام التي أدخلها صاحب المشروع، جميعها بالدرهم المغربي.
- **أسعار الشحن من الصين**: ملف PDF بعنوان `Plaquet COD AFRICA La chine (1).pdf` الصادر من COD IN AFRICA، الأسعار بعملات XOF / XAF / GNF / USD حسب الدولة؛ لا تتضمن الصفحة تاريخ صلاحية.
- **أسعار الصرف**: تُجلب تلقائياً من واجهة [fawazahmed0/exchange-api](https://github.com/fawazahmed0/exchange-api) (محدثة يومياً). عند عدم الاتصال يُستخدم **سعر تقديري احتياطي** مع رسالة واضحة، ويمكن تعديله يدوياً من داخل التطبيق. السعر النهائي دائماً بالدرهم المغربي.
- تعريفة الشحن نفسها **قابلة للتغيير** بحسب المزود؛ تحقق منها قبل الشحن.

### تعديل بيانات الدول

افتح `app.js` ثم غيّر الأسعار داخل `COUNTRIES`. مثلاً:

```js
{ id: 'SN', label: '🇸🇳 السنغال', service: 84, dubai: 134, china: null }
```

## النشر على GitHub Pages

1. أنشئ مستودعاً عاماً على GitHub.
2. ارفع الملفات `index.html` و`style.css` و`app.js` و`README.md` إلى جذر المستودع.
3. افتح **Settings → Pages → Deploy from a branch**، وحدد **main** و **/(root)**.
4. سيصبح التطبيق متاحاً على رابط شبيه بـ `https://USERNAME.github.io/REPOSITORY/`.

للتشغيل محلياً: افتح ملف `index.html` في المتصفح. خط Cairo يحتاج الإنترنت للتحميل أول مرة، وفي حال غيابه تستخدم خطوط النظام.
