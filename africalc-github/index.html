مهم قبل اتخاذ قرار الاستيراد

رأس مال الاستيراد هنا يشمل ثمن المخزون والشحن فقط، ولا يشمل الميزانية الإعلانية المسبقة. تُحتسب رسوم الخدمة والإعلانات داخل سعر البيع لكل قطعة. قد توجد مصاريف إضافية غير مشمولة، مثل الجمارك والضرائب ورسوم التحويل والمرتجعات وتغيّر سعر الشحن أو اعتماد الوزن الحجمي والحد الأدنى المحاسَب؛ تحقّق منها مع المورّد وشركة الخدمات. الأسعار المستخدمة هي القيم التي زُوّدت بها الحاسبة ويمكن تعديلها لاحقاً.
